## 功能完整介紹 (v0.6.0 final feature surface)

### 1. 多 Provider LLM 集成

**寫程式 (Rust)**:
- `crates/line-hub-core/src/provider.rs` — LLM provider 抽象
- 內建 adapters 對接:
  - **MiniMax M3** (預設, MiniMax 發的)
  - **OpenAI** (gpt-4o / gpt-4-turbo / custom)
  - **Anthropic** (claude-3.5-sonnet / claude-3-haiku)
  - **Ollama** (本地, http://localhost:11434/v1)
- API key 透過 OS keyring 存, **絕不出現在 config.json**
- Per-provider `max_tokens` + 預設 model 自動選
- SSE streaming + JSON tool-call 兩種 protocol 統一 wrap

**UI (SettingsDialog)**:
- API key input (4 行: MiniMax / OpenAI / Anthropic / Ollama base URL)
- 即時 validate 後送 `save_config`
- Ollama 走 `base_url` 而非 api_key

### 2. LINE Desktop MCP Bridge

**追蹤 line-desktop-mcp v3.0.0** (29 tools)。

**Server.js spawner** (`commands.rs::spawn_mcp`):
- 從 Settings dialog 拿 `line_mcp_path` (預設 `C:\Tools\line-desktop-mcp\src\server.js`)
- 啟動 Node.js child process; pipe stdin/stdout
- Initialize handshake; 後續 IPC call_tool with JSON-RPC 2.0
- 失敗有 graceful error，**不** panic

**Tool Registry** (`crates/line-hub-core/src/mcp.rs`):
- `Arc<RwLock<ToolRegistry>>` — 線程安全
- `registry_sink()` 早期 v0.4.0 是 `unimplemented!()` (panic) — v0.5.0 已修 (commit `80f756c`)

**Typed result blocks** (v0.5.0+, line-desktop-mcp v3.0.0 升級):
- `call_tool_structured()` decode Content[] 進 `ToolResultBlock`:
  - `Text` (string content)
  - `Image` (base64 data + mime type)
  - `Audio` (base64 data + mime type)
  - `Unsupported` (fallback)
- Image bytes 走 Tauri event channel → inline `data:` URL → React `<img src>`

### 3. Agentic Chat Loop (`commands::chat` → `conversation::run_turn`)

★ **AI 可以 call 工具 → 看結果 → 再 call 工具 → ... → 最終答案** (不是被限制 single-turn stream)。

- 上限 8 tool turns per message
- Each turn emit `UiEvent` (ToolArgs / ToolDone / StreamDelta / Final / Error / SendBlocked)
- Frontend 用 `listen('chat-event')` 順序 render

### 4. Native Send-Guard (安全防護)

**防止 AI 偷送訊息到 LINE**:
- 對 `send_*` / `stage_line_reply` / `set_line_draft` 等 LINE-mutating tools
- 在 Tauri command layer (`TauriSendGuard`) 跳出 **native OS confirmation dialog** (`tauri-plugin-dialog`)
- Approve → 工具真的跑
- Reject → 回傳 `SendBlocked` trace，loop 還能繼續, model 看 trace 解釋給 user
- Approval 在一個 `run_turn` session 內保存 (整段對話都記得 session 開頭的許可)

### 5. Local-Only Mode Toggle (v0.6.0 頭牌新功能)

★ **沒裝 CUA Driver / Python / SQLite3MC DLL** 也能用 app。

- Settings dialog 加 checkbox 「**本地只讀模式**」 (zh-TW label)
- 勾選 → persist `~/.line-hub/config.json::local_only`
- `build_system_prompt(tools, active_chat, local_only: bool)` 第三參數
- 啟用時 system prompt **自動隱藏 8 個 LINE-mutating tools**:
  - `send_message_auto`, `send_message_manual`, `send_file_manual`
  - `stage_line_reply`, `stage_line_forward`
  - `set_line_draft`, `clear_line_draft`
  - `open_line_chat`, `open_line_chat_feature`
  - `export_line_chat_history`
- **MCP child 仍 spawn** (保留本地 DB reader)
- 用 user 用 LINE app 手動點 send 也可以 (我們只 control model 看什麼)

**Use case 設計原因**: 沒裝 GUI 前置的 developer 仍能用 app **讀** LINE message + 查 capabilities + search + verify + copy + translate

### 6. MCP Auto-Respawn Framework (v0.6.0 skeleton)

**防止 LINE 改版導致 MCP child 整個掛掉而 app 還在跑**:
- `crates/line-hub-tauri/src/respawn.rs` (新檔, 130 行)
- `RespawnState { enabled, attempts, last_attempt_unix_ms }`
- `RESPAWN_BACKOFF: [Duration::from_secs(1), 2, 4]`
- `MAX_RESPAWN_ATTEMPTS = 3` (失敗超過放棄，讓 user 手動 re-spawn)
- Helper API: `mark_alive(state)` / `mark_failed(state)` / `trigger_respawn(state)`
- **3 unit tests cover**: backoff stage walk; disabled means no respawn; mark_alive resets attempt counter

**完整 watcher task wiring** (chat-loop call site → trigger `mark_failed` → spawn respawn task) 是 v0.6.1 follow-up；framework 已就位。

### 7. Capabilities Health Card (v0.5.0+)

- App 啟動 spawn MCP 後立刻 `get_line_capabilities({mode:"all"})`
- 顯示 in UI:
  - 工具總數 (29)
  - buckets: direct / uia / guided_ui / unavailable_windows
  - 哪些功能在這台機可跑 / 不可跑
- 沒 spawn MCP 時，return synthetic "spawn MCP first" payload, 不會卡

### 8. Asia/Taipei Timezone Helpers (v0.5.0+)

**不管 OS 在哪個 tz，date filter 一律 `+08:00`**:
- `crates/line-hub-core/src/tz.rs`
- `tz::local_midnight_to_utc(date)` + `tz::today_local()`
- 3 unit tests: round-trip + bad-input cases
- 對齊 line-desktop-mcp v3.0.0 自己固定 +08:00 的行為

### 9. Tool Categorization (v0.5.0+)

- `commands::categorize_tool(name) -> &'static str`
- 從 v0.4.0 的 8-category heuristic 擴展到 **29 tools** 全 explicit arm
- 沒有 silent fallthrough 到 `other`

### 10. Build System Prompt v3 Hints (v0.5.0+)

- `commands::build_system_prompt(tools, active_chat, local_only)`
- 4 條 v3.0.0 hints 自動寫入 prompt:
  1. 偏好 `get_line_local_messages`
  2. inspect screenshot before `confirm_*` (visual verification)
  3. 先跑 `prepare_line_workflow` 再分階段執行
  4. Asia/Taipei tz

### 11. OS Keyring API Keys

- `keyring` crate (cross-platform)
- 加密在 platform credential store (Windows Credential Manager / macOS Keychain / Linux secret-service)
- **API key 絕不寫入 config.json**

### 12. SQLite Streaming History

- **不限於 LLM context window**: SQLite streaming 一次性拉會話歷史
- model 需要時 streaming 進 context, 不一次灌爆
- `conversation.rs` 內建
- 6 unit tests cover pause/resume/snapshot

### 13. Cancel Streaming Button

★ v0.2.x 已接好 UI button，**P0-1 gap-analysis 過時記錄**是 stale (v0.6.0 重新 verify 過):
- 用戶長按到一半可立即 `cancel_chat(session_id)` 把 spawn task kill 掉

### 14. Multi-Session Conversation Sidebar

- List chat session (`list_history_sessions` / `rename` / `delete`)
- 每 session 都持久化到 SQLite
- Active session 切換可直接 render 歷史

### 15. Per-Provider max_tokens + Default Model

- `HubConfig::providers[].default_model`, `max_tokens`
- 預設不指定 → 自動挑第一個 `is_default: true` 的 model

## Build Pipeline (建構流程)

```
GitHub Actions on push to main OR tag v*:
┌──────────────────────────────────────────────────────────┐
│ 1. Checkout                                              │
│ 2. Setup Node.js (for UI build)                          │
│ 3. Setup Rust toolchain                                  │
│ 4. Install cached cargo + node deps                     │
│ 5. Cargo test (workspace) — gates release               │
│ 6. Run npm ci + vite build (UI bundle)                   │
│ 7. Install Tauri CLI                                     │
│ 8. Run cargo tauri build (Windows)                       │
│    → produces target/release/line-model-hub.exe (~18MB)  │
│    → produces target/release/bundle/nsis/*-setup.exe     │
│      (Line 小幫手_0.6.0_x64-setup.exe, ~4.6MB)          │
│ 9. Upload line-model-hub-windows artifact               │
│    (id=10289448523 for v0.6.0, expires after 90d)        │
│ 10. If tag push: attach artifact to GitHub Release       │
└──────────────────────────────────────────────────────────┘
```

**已知 issues**:
- **MSI bundle stage fail** in windows-latest runner (WiX 3.14 / `light.exe`) — 已解: 只 ship NSIS
- **GitHub 把中文檔名 sanitize**: `小幫手` 三個中文字 strip 成 `Line._0.6.0_...` — 這是 GitHub asset 命名規則限制, 沒改; 檔案內容 100% 正確
- **tag-only GitHub Actions run 失敗因 MSI glob**: v0.5.2 commit `bdf13de` 修, 用 `if-no-files-found: warn` 容錯
